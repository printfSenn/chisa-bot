# chisa bot

tsundere discord bot. she talks when she wants to.

## setup

1. get a discord bot token from discord.com/developers
2. get a free groq key from console.groq.com
3. rename .env.example to .env and fill it in
4. npm install
5. node bot.js

## thats it

keep the terminal open or she dies. change CHANCE in bot.js if shes too quiet or too loud. 0.3 is fine.
